# Проверка этапа 3 — FastAPI и подключение к БД

## Реализовано

- FastAPI-приложение с общей точкой доступа для обоих клиентов.
- SQLAlchemy-подключение, настраиваемое переменной `DATABASE_URL`.
- API-маршруты для проверки доступности сервиса, чтения типов сотрудников, помещений, подразделений и сотрудников.
- Добавление типов сотрудников и помещений с проверкой пустого названия и обработкой дубликатов.
- HTTP-эндпоинт отчёта, который загружает данные из БД и вызывает общий бизнес-слой этапа 2.
- Pydantic-валидация входных параметров отчёта: выбранные подразделения и помещения обязательны, период корректен, пороги неотрицательны.
- Базовые HTTP-тесты.

## Проверки

Локально выполнено: `python -m pytest -q` — **16 тестов пройдены**.

В API-тестах используется SQLite для проверки независимых от PostgreSQL HTTP-ответов и валидации входных данных. PostgreSQL-схема не запускалась в этой среде, поэтому успешное подключение к реальному PostgreSQL и поведение всех FK/индексов здесь не заявляются как проверенные.

## Маршруты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка API |
| GET / POST | `/api/reference/employee-types` | Список / добавление типа сотрудника |
| GET / POST | `/api/rooms` | Список / добавление помещения |
| GET | `/api/departments` | Список подразделений |
| GET | `/api/employees` | Список сотрудников |
| POST | `/api/reports/employees` | Отчёт по выбранным условиям |

## Что ещё не входит в этап

- Создание/редактирование сотрудников и подразделений через API.
- Операции начала и завершения рабочего дня.
- Интеграционные тесты против реального PostgreSQL.
- UI веб-клиента и настольного клиента.
- Авторизация: по согласованию учебный вариант остаётся без неё и предназначен только для доверенной локальной сети.

## Команды запуска

```bash
python -m pip install -r requirements.txt
# Создать .env на основе .env.example и настроить DATABASE_URL
psql "$DATABASE_URL" -f database/001_schema.sql
uvicorn webapp.main:app --host 0.0.0.0 --port 8000
```

Затем открыть `http://127.0.0.1:8000/docs`.
